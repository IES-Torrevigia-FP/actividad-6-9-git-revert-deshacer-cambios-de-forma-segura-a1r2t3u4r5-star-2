##EXPLICACIÓN

En un entorno colaborativo, la diferencia entre
git revert HEAD y git reset --hard HEAD~1 depende de cómo manejan el historial de commits y el riesgo que representan para el trabajo de otros desarrolladores.
Revert es seguro para compartir, reset --hard es solo para cambios locales.
